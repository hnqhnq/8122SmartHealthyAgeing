## 第 0 步：检查是否已经装了 conda / Step 0: is conda already installed?

打开终端：
- **Windows**：开始菜单里搜索 **Anaconda Prompt** 并打开（推荐用它，不要用普通的 cmd）。
- **Mac**：打开"终端"（Terminal）。

输入：

```bash
conda --version
```

- 显示类似 `conda 24.x.x` → 已经装好，跳到第 2 步。
- 显示 `'conda' 不是内部或外部命令` 或 `command not found` → 做第 1 步。

## 第 1 步：安装 Anaconda / Step 1: install Anaconda

从清华镜像下载（比官网快得多）：
https://mirrors.tuna.tsinghua.edu.cn/anaconda/archive/

在页面里找**最新日期**的、符合你电脑的安装包：

| 电脑 / computer | 文件名里包含 / filename contains |
|---|---|
| Windows | `Windows-x86_64.exe` |
| Mac，M1/M2/M3/M4 芯片（Apple Silicon） | `MacOSX-arm64.pkg` |
| Mac，Intel 芯片 | `MacOSX-x86_64.pkg` |

不知道自己的 Mac 是哪种芯片：点左上角苹果图标 →"关于本机"，看"芯片"一栏。

安装时注意：
- **安装路径不要有中文和空格**。Windows 默认的 `C:\Users\你的用户名\anaconda3` 如果用户名是中文，请改成 `C:\anaconda3`。
- 其他选项保持默认，一路"下一步"。

装完**关掉终端再重新打开**，回到第 0 步检查。

## 第 2 步：把 conda 的下载源换成清华镜像 / Step 2: use the Tsinghua mirror

国内直连 conda 官方源很慢。依次输入这三行（每行回车一次）：

```bash
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main
conda config --set show_channel_urls yes
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

第三行让以后的 `pip install` 也自动走清华镜像。

## 第 3 步：创建 `pytorch` 环境 / Step 3: create the environment

```bash
conda create -n pytorch python=3.10 -y
```

- `-n pytorch`：环境的名字叫 pytorch。
- `python=3.10`：用 Python 3.10（我们测试过的版本；3.11、3.12 也可以）。
- `-y`：自动回答"是"，不用中途确认。

如果提示 `CondaValueError: prefix already exists`，说明你已经有这个环境了，直接做下一步。

## 第 4 步：进入环境，安装包 / Step 4: activate and install packages

```bash
conda activate pytorch
pip install torch numpy pandas scikit-learn matplotlib -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**激活成功的标志**：命令行最前面从 `(base)` 变成 `(pytorch)`。
**以后每次打开新终端都要先 `conda activate pytorch`**，否则会找不到这些包。

各个包是干什么的：

| 包 / package | 用途 / purpose | 哪个练习 |
|---|---|---|
| `pandas` | 读表格 | C |
| `scikit-learn` | 机器学习模型 | C |
| `matplotlib` | 画图 | C、D |
| `torch` | PyTorch 深度学习框架（约 200 MB，最大的一个） | D |
| `numpy` | 读数据文件 | D |

## 第 5 步：检查是否装好 / Step 5: check

```bash
python -c "import torch, numpy, pandas, sklearn, matplotlib; print('全部装好了', torch.__version__)"
```

看到 `全部装好了 2.x.x` 就成功了。

## 第 6 步：进入练习文件夹，运行 / Step 6: go to the folder and run

终端里要先 `cd` 到练习所在的文件夹，否则程序找不到数据文件。

**Windows**（假设你把练习放在桌面的 `exercises` 文件夹）：

```bash
cd %USERPROFILE%\Desktop\exercises\C-leakage
python train.py
```

**Mac**：

```bash
cd ~/Desktop/exercises/C-leakage
python train.py
```

小技巧：输入 `cd ` （cd 后面有一个空格），然后把文件夹从资源管理器 / 访达里**拖进终端窗口**，路径会自动填好，再按回车。

Windows 上如果练习在 D 盘等其他盘，先输入 `D:` 回车切换盘符，再 `cd`。

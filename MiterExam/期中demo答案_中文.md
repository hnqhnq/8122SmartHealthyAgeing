# Demo 答案（中文）

计算机方向。第 1、3 部分用原型 3 和原型 4。第 2 部分只比较 1 号和 3 号。

## 工作原理（30%）

张先生独居，有跌倒史，也可能忘记日常事务。我把摄像头跌倒警报和桌面陪伴组合在一起。两者都不必佩戴。血压仍由他平时的医疗照护负责。

`摄像头 → 姿态估计 → 倒下且起不来则判定为跌倒 → 给家人发消息`

`时钟 + 触摸 → 用药提示和动画眼睛 → 到时仍未触摸 → 给家人发消息`

摄像头负责家里没有别人看见的跌倒。桌面陪伴负责漏服的药物。

## 方法比较（30%）

**1 号可穿戴。** 最大优点是隐私：它发送动作警报，不拍摄家里。最大缺点是必须佩戴并充电。有轻度记忆减退时，忘了夹上就意味着跌倒不会发出任何警报。

**3 号摄像头。** 最大优点是没有佩戴这一步，所以他忘了设备，被监测的房间仍然覆盖得到。最大缺点是私人房间里有摄像头，坐下、弯腰或宠物经过还会造成误报。

## 本专业视角（40%）

从计算机来看，原型 3 的限制是泛化。演示只是一个房间、一个摄像头角度、一个人。真实的家会改变光线、家具和姿态，所以演示集上的准确率不能说明同一个模型在那里仍然有效。漏掉的跌倒没有旁人看见；反复误报会让家人不再理会警报。

评价：把跌倒标成在固定时间内倒下且没有起来。按家庭划分，不按帧划分。阈值只在训练家庭上选择。在新家庭上报告敏感性和每天误报次数，不报告准确率。只有敏感性至少保持 0.90、每天误报少于 1 次才使用。否则，只在水平姿态持续一段时间后再发出警报。
